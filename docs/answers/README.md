# Answers

**Reasoning worth keeping.** When a question gets worked through properly — a design
call, an engine question, a "would this work" — the answer is written here rather than
left in a chat that nobody can read afterwards.

The reason this folder exists: Claude starts every session with no memory of the last
one. `CLAUDE.md` loads automatically, the rest gets read on request, and anything that
only ever existed in conversation is gone. Without this, the same ground gets covered
twice.

**How this differs from `decisions.md`:** that file records *what* was settled, one
dated line, binding. This folder holds *why*, and the thinking on things that were
never settled at all. Most answers here never become decisions. When one does, the
decision line links back to the answer file — the ruling lives there, the reasoning
lives here, neither restates the other.

Filenames are `YYYY-MM-DD-slug.md`.
